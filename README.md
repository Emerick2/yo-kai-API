# Yo-kai Watch API

Une API REST statique simple et gratuite pour récupérer des données sur l'univers de Yo-kai Watch (Noms, descriptions, étymologies, et images).
*A simple and free static REST API to fetch data about the Yo-kai Watch universe (Names, descriptions, etymologies, and images).*

---

## 🇫🇷 Français

### Structure du Projet

L'API est organisée de manière à être appelée facilement via l'ID du Yo-kai :

* **Données :** `/data/yokai_data/{id}.json`
* **Images :** `/data/picture/{id}.png`

### Utilisation

Pour récupérer les données d'un Yo-kai (ex: Jibanyan, ID #95) en JavaScript :

```javascript
const yokaiId = 95;
const url = `https://emerick2.github.io/yo-kai-API/data/yokai_data/${yokaiId}.json`;

fetch(url)
  .then(response => {
    if (!response.ok) throw new Error('Yo-kai non trouvé');
    return response.json();
  })
  .then(data => {
    console.log("Nom : " + data.nom);
    console.log("Description : " + data.description);
  })
  .catch(error => console.error(error));

```

### Récupérer une image

L'image correspondant au Yo-kai est accessible directement via :
`https://emerick2.github.io/yo-kai-API/data/picture/1.png`

## 🇺🇸 English

### Project Structure

The API is organized to be easily queried using the Yo-kai ID:

* **Data:** `/data/yokai_data/{id}.json`
* **Pictures:** `/data/picture/{id}.png`

### Usage

To fetch data for a specific Yo-kai (e.g., Jibanyan, ID #1) using JavaScript:

```javascript
const yokaiId = 1;
const url = `https://emerick2.github.io/yo-kai-API/data/yokai_data/${yokaiId}.json`;

fetch(url)
  .then(response => {
    if (!response.ok) throw new Error('Yo-kai not found');
    return response.json();
  })
  .then(data => {
    console.log("Name: " + data.nom);
    console.log("Etymology: " + data.etymologie);
  })
  .catch(error => console.error(error));

```

### Fetching an Image

The image corresponding to the Yo-kai is available at:
`https://emerick2.github.io/yo-kai-API/data/picture/1.png`

## Contribution

### 🇫🇷 Comment aider ?

Si vous souhaitez ajouter des données manquantes ou corriger une erreur :

1. **Forkez** le projet.
2. Modifiez le fichier `medalium.csv` (ne modifiez pas directement les fichiers JSON, car ils sont générés automatiquement par le script Python).
3. Proposez une **Pull Request**.

### 🇺🇸 How to help?

If you want to add missing data or fix an error:

1. **Fork** the project.
2. Edit the `medalium.csv` file (do not edit JSON files directly, as they are auto-generated by the Python script).
3. Submit a **Pull Request**.
